# acp-desktop

Unofficial desktop client for a **local coding-agent CLI** over [ACP](https://agentclientprotocol.com) (JSON-RPC on stdio).

**Not affiliated with, endorsed by, or a product of xAI.**  
“Grok” and related marks belong to their owners. This repo does not ship any vendor CLI or credentials.

自己本机已安装并登录的 agent CLI（例如官方 `grok`）由本应用拉起 `agent stdio`。改文件、跑命令默认要你点头。

## Status

Scaffold only. No app yet.

## Requirements (planned)

- macOS first
- A local ACP-capable CLI on `PATH` (install and log in yourself)
- This app will not redistribute vendor binaries
